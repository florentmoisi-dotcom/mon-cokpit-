# Mon Cockpit

Application mobile locale sans compte, avec tâches, journal trail, finances et notes.

## Mise en ligne avec GitHub Pages
1. Dans le dépôt GitHub `mon-cokpit-`, choisir **Add file > Upload files**.
2. Ajouter `index.html` à la racine du dépôt et valider avec **Commit changes**.
3. Ouvrir **Settings > Pages**. Sous **Build and deployment**, sélectionner **Deploy from a branch**, branche `main`, dossier `/(root)`, puis **Save**.
4. Après publication, ouvrir `https://florentmoisi-dotcom.github.io/mon-cokpit-/` dans Safari sur iPhone.
5. Dans Safari, utiliser **Partager > Sur l'écran d'accueil**.

Les données sont stockées dans `localStorage` du navigateur. Elles ne sont pas synchronisées entre appareils. Utiliser l'export JSON dans l'onglet Sauvegarde. GitHub Pages est public : ne pas mettre de données privées dans le code source.
